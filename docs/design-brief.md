# Дизайн-система B: «рентген трактора»

Согласованные макеты: `docs/mockups/home-desktop-b-xray.png` (десктоп) и `docs/mockups/home-mobile-b-xray.png` (три мобильных экрана). Вид сайта сверяется с ними.

## Идея

Сайт механика по электрике, а не агентский лендинг. Центр первого экрана — растровая иллюстрация трактора, сквозь прозрачный корпус которого светится проводка. Посетитель выбирает симптом, и подсвечивается цепь, где чаще всего сидит причина. Вся смелость потрачена на этот экран. Остальные блоки спокойные: строки прайса, шаги, карточки запчастей, вопросы.

## Принципы

1. Одна яркая вещь — «рентген». Всё остальное тише: без градиентных заливок, без анимаций при прокрутке.
2. Цвет несёт смысл. Зелёный `--live` — живой ток и фокус, `--fault` — только неисправность и ошибки форм, `--frost` — только климат. Жёлтого нет.
3. Услуги читаются как прайс механика: строка, суть, цена «от», стрелка.
4. Тексты от лица механика, без штампов. Никаких надписей капсом над заголовками, строк через «·», стрелок в тексте кнопок, выделенного слова в заголовке.
5. Регионы на главной не называются. Они есть на /regiony/, страницах краёв, /kontakty/, /dostavka/ и в JSON-LD.
6. Телефон доступен на всех ширинах: в шапке и в липкой панели до 768 px.

## Токены (`src/assets/css/main.css`, `:root`)

| Токен | Значение | Где |
|---|---|---|
| `--bg` | #EEF2EC | фон страницы |
| `--surface` | #FFFFFF | плоскости, карточки |
| `--ink` | #12261A | текст |
| `--muted` | #4F6357 | вторичный текст (5,6:1 на `--bg`) |
| `--forest` | #0F3D22 | заголовки, подвал |
| `--brand` | #1F7A35 | кнопки, ссылки (белый текст 5,4:1) |
| `--live` | #7BC74D | ток, кольцо фокуса, отметки |
| `--frost` | #4A90D9 | только климат |
| `--fault` | #E04A33 | точка неисправности, рамка ошибки; текст ошибки — `--fault-ink` #B3321F |

Производные: `--brand-strong`, `--tint`, `--tint-live`, `--line`, `--line-strong`, `--fault-tint`, `--on-forest`, `--grid-line` (миллиметровка первого экрана).

Шрифты (самохостинг woff2 в `src/assets/fonts/`, `font-display: swap`):
- `--font-display` — Unbounded 600/700: H1, H2, номера шагов, крупный телефон;
- `--font-text` — Golos Text 400/600: всё остальное.

В preload — Unbounded 700 и Golos Text 400, кириллица.

Шкала: `--step-0…--step-5` = 16/18/22/28/40/56. H1 28→40, H2 22→28, H3 18, текст 16, лид 18, заголовок фото-полосы до 56.

Скругления по иерархии: `--r-btn` 12, `--r-field` 10, `--r-card` 16, `--r-plane` 24, пилюли симптомов `--r-pill` 999.

Отступы: сетка 8 px, `--space-section` 32–48 px сверху и снизу блока, контейнер 1200 px, поля 16/24 px. Цели касания не меньше 44 px (`--tap`), кнопки 48 px.

## «Рентген» первого экрана

- Картинки `src/assets/images/xray/tractor-xray-<system>.png` (1536×1024) выводятся через `{% image %}` в `<picture>`. Активная — eager и `fetchpriority=high`, остальные — lazy и не показываются, пока `xray.js` не поставит `data-xray-ready` (первое наведение, фокус, клик или простой).
- Картинки ложатся на `--bg` через `mix-blend-mode: multiply`, под ними CSS-миллиметровка.
- Подписи узлов и точка неисправности — HTML в процентах от картинки. Координаты и описание вариантов — в `src/index.11tydata.js`.
- Смена варианта — перекрёстное проявление 300 мс. Точка переезжает за 300 мс и пульсирует. При `prefers-reduced-motion` всё без анимации.
- Без JS симптомы — ссылки на страницы услуг.
- Симптомы редактируются в Sveltia (страница «Главная», поле «Симптомы»): надпись, система, услуга, подсказка «Чаще всего причина».

## Шаги на главной

Пункт списка `steps` из `pages/home.md` можно записать как «Заголовок: пояснение». Тогда заголовок выводится крупно, пояснение под ним.

## Проверка

`npm test` проверяет поведение «рентгена» (`tests/xray.test.mjs`), шрифты и отсутствие Manrope, подвал без краёв, липкую панель и бюджет: CSS ≤ 40 КБ, JS ≤ 30 КБ gzip.
