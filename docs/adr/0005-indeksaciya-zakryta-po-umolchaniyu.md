# 0005. Индексация закрыта по умолчанию

## Контекст

Домена и хостинга нет, содержимое тестовое (демо-позиции и заглушки вместо адреса и реквизитов). Задача сайта при этом найтись в Яндексе и в нейропоиске.

## Решение

Каждая страница по умолчанию получает `noindex,nofollow`, а `robots.txt` закрывает весь сайт. Индексация включается только при `INDEXABLE=true` и заданном `SITE_URL`, начинающемся с `https://`.

## Почему

- Открытая индексация по умолчанию отвергнута: при случайной выкладке в поиск попали бы демо-товары, выдуманные цены и видимые заглушки вроде `[АДРЕС — впиши]`. Убрать такие страницы из выдачи Яндекса дольше, чем их закрыть.
- Один флаг без домена недостаточен, поэтому нужны оба условия. Включить индексацию на адресе вроде localhost не получится.

## Последствия

- Забытый `INDEXABLE` после запуска означает невидимый сайт. Это надо проверять в чеклисте запуска.
- Тесты сборки проверяют режим «закрыто» по умолчанию, но режим «открыто» требует отдельной проверки на боевом адресе.
- Метаданные для Яндекса (sitemap, Clean-param, разметка) строятся всегда, но поисковики их не видят, пока индексация закрыта.
