# 0001. Статический генератор Eleventy

## Контекст

Нужен лёгкий сайт из готовых HTML-страниц, который читает файлы Markdown/JSON, написанные Sveltia. Эталон для сравнения, каталог engine.cmteh.ru, был доступен как готовая основа.

## Решение

Сайт собирается Eleventy 3 (Node 22 и выше) с шаблонами Nunjucks. Изображения превращает в AVIF и WebP `@11ty/eleventy-img`. Клиентский JS пишется на чистых ES-модулях без фреймворков.

## Почему

- Форк каталога engine.cmteh.ru отвергнут: код минифицирован, а контент вшит в Python. Править такой код нельзя, а владелец не смог бы менять содержимое через Sveltia.
- Eleventy читает Markdown/JSON напрямую, по умолчанию не добавляет JS, и шаблоны остаются читаемыми. Вёрстка и данные разделены, чего у cmteh не было.
- JS-фреймворки исключены бюджетом: JS до 30 КБ и CSS до 40 КБ в сжатом виде на страницу.

## Последствия

- Для сборки нужен Node 22 и выше, а на целевом хостинге Node поставить нельзя. Собирать приходится вне хостинга, на хостинг уезжает готовый `dist/`.
- Каждая правка в Sveltia требует пересборки. Живого редактирования на сервере нет.
- Смена генератора позже означает переписывание всех шаблонов и логики адресов. Данные в Markdown/JSON при этом сохраняются.
