# 0006. D01: адрес API MAX — platform-api2.max.ru

## Контекст

План предполагал, что Bot API MAX живёт на `https://platform-api.max.ru`. Исполнителю предписывалось сверить формат запроса с документацией.

## Решение

Бот MAX работает с адресом `https://platform-api2.max.ru`. Он вынесен в переменную `MAX_API_URL`, значение по умолчанию задано в конфигурации. Это записано как D01.

## Почему

- Сверка с dev.max.ru при сборке показала, что документация указывает `platform-api2.max.ru`, а не адрес из плана.
- Жёстко прописанный адрес отвергнут: адрес API уже оказался не тем, что ожидали, и может измениться снова. Переменная позволяет исправить его без правки кода.
- Адрес нужен ради R28i: без него заявки не доходят в MAX.

## Последствия

- Другие места, где остался старый адрес (спецификация, примеры), надо исправлять. В спецификации он указан до сих пор.
- Адрес подтверждён документацией, но не проверен живым ботом: ключей `MAX_BOT_TOKEN` и `MAX_CHAT_ID` ещё нет. Работу канала нужно проверить при первых настоящих ключах.
- Канал MAX в режиме «только журнал» пропускается, поэтому ошибку в адресе тесты не поймают.
