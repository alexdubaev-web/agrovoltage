# Спецификация: редизайн АГРОВОЛЬТАЖ (направление B — «рентген трактора»)

## Задача

Заказчик посмотрел сайт и оценил его как «убожество». Нужен красивый, интересный и удобный сайт: переделаны все страницы, нормальные тексты, заголовки по правилам SEO. Первая попытка с SVG-схемой трактора отвергнута («реализация через svg гавно»). Графика генерируется через /codex-image. Макет согласован 2026-11-04: вариант B.

## Решение

Вид сайта задают два согласованных макета:
- `docs/mockups/home-desktop-b-xray.png` — главная на десктопе;
- `docs/mockups/home-mobile-b-xray.png` — три мобильных экрана.

Главная повторяет их по порядку блоков, раскладке, палитре и шрифтам. Внутренние страницы собраны из тех же компонентов.

Центр первого экрана — растровая «рентген»-иллюстрация трактора. Она сгенерирована через /codex-image, сквозь прозрачный корпус светится проводка. Посетитель выбирает симптом, и иллюстрация плавно сменяется вариантом с подсвеченной цепью. Поверх картинки HTML показывает:
- подписи узлов;
- красную точку неисправности;
- карточку «Чаще всего причина…» с услугой, ценой и кнопкой «Записаться».

Регионов на главной нет. Тексты переписаны языком механика. SEO-иерархия заголовков проверяется тестом. Функции работают как раньше: каталог, корзина, формы, Sveltia, SEO-разметка.

## Решения по реализации

- Стек не меняется: Eleventy 3, Nunjucks, один `main.css`, vanilla JS. Новый модуль `src/assets/js/xray.js` подключается полем страницы `scripts`.
- Шрифты уже лежат в `src/assets/fonts/`, самохостинг woff2:
  - Unbounded 600/700 — заголовки;
  - Golos Text 400/600 — текст.

  Manrope убирается из CSS и preload.
- Палитра B задаётся токенами:

  | Токен | Цвет | Где |
  |---|---|---|
  | `--bg` | #EEF2EC | фон страницы |
  | `--surface` | #FFFFFF | плоскости |
  | `--ink` | #12261A | текст |
  | `--muted` | #4F6357 | вторичный текст |
  | `--forest` | #0F3D22 | заголовки и подвал |
  | `--brand` | #1F7A35 | кнопки |
  | `--live` | #7BC74D | «живой ток», фокус, акценты |
  | `--frost` | #4A90D9 | только климат |
  | `--fault` | #E04A33 | только точка неисправности и ошибки форм |

  Жёлтого нет. Под иллюстрацией тонкая сетка «миллиметровки» из CSS.
- Иллюстрация трактора генерируется через /codex-image (тикет 00, делает оркестратор):
  - сгенерированный PNG — исходник;
  - фон картинки светлый, на `--bg` она ложится через `mix-blend-mode: multiply`;
  - подписи, точка и карточка — HTML поверх картинки, текст не запекается.
- Остальные картинки остаются прежними. Hero-фото `home-hero.jpg` переезжает в полосу «Выезжаем к технике». Миниатюры услуг, фото товаров и статей используются как в макете.
- SEO-правила проверяет новый тест `tests/seo-headings.test.mjs` по всему dist/.
