# Спецификация: редизайн АГРОВОЛЬТАЖ

## Задача

Заказчик посмотрел сайт и оценил его как «убожество»: он выглядит шаблонно, тексты слабые. Нужен красивый, интересный и удобный сайт. Переделать нужно все страницы, тексты должны быть нормальными, заголовки — по правилам SEO. Дизайн задаётся скиллом /frontend-design.

## Решение

Сайт получает свою визуальную идентичность из мира диагностики электрики (`docs/design-brief.md`). На первом экране главной — интерактивная электрическая схема трактора: посетитель выбирает симптом, загорается нужная цепь, рядом появляется подходящая услуга. Все страницы собраны в одной системе: палитра Field/Ink/Leaf/Copper/Frost/Fault, шрифты Unbounded и Golos Text, раскладка по брифу. Все тексты переписаны языком механика, коротко и по делу. У каждой страницы правильная SEO-иерархия заголовков и мета-теги. Функции (каталог, корзина, формы, Sveltia, SEO-разметка) работают как раньше.

## Решения по реализации

- `docs/design-brief.md` — часть этой спецификации: палитра, шрифты, раскладка главной и принципы берутся оттуда дословно. Страницы регионов (/regiony/ и /regiony/<край>/) делаются по той же системе: лид, населённые пункты, услуги строками, FAQ, форма.

- Стек не меняется: Eleventy 3, Nunjucks, один `main.css`, vanilla JS. Новый модуль `src/assets/js/symptoms.js` подключается полем страницы `scripts`.
- Шрифты Unbounded 600/700 и Golos Text 400/600, woff2 самохостингом, уже лежат в `src/assets/fonts/`. Manrope убирается из CSS и preload.
- Картинки остаются прежние, сгенерированные через /codex-image. Hero-фото переезжает в полосу «Выезжаем к технике».
- Схема трактора — инлайн-SVG в partial `src/_includes/partials/tractor-schematic.njk`. Цепи размечены `data-system`.
- SEO-правила проверяет новый тест `tests/seo-headings.test.mjs` по всему dist/.
