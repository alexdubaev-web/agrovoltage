## Что должно заработать

Сайт выглядит как согласованный макет B. Новая визуальная система: палитра, шрифты Unbounded и Golos Text, шкала, скругления, компоненты. Новые шапка и подвал, мобильная липкая панель «Позвонить» / «Заявка», модальное окно заявки и баннер согласия.

Главная повторяет `docs/mockups/home-desktop-b-xray.png` блок за блоком:
1. Hero: слева H1, лид, кнопки, «Что случилось?» и симптомы-пилюли; справа «рентген» трактора с подписями узлов, точкой неисправности и карточкой «Чаще всего причина…».
2. Услуги строками по группам.
3. «Как проходит ремонт» — 4 шага на линии.
4. Фото-полоса «Выезжаем к технике».
5. «Запчасти в наличии» — 4 карточки товаров.
6. FAQ рядом со статьями.
7. Контакт-полоса «Обсудим вашу задачу» с формой.
8. Тёмно-зелёный подвал.

На мобильных — как `docs/mockups/home-mobile-b-xray.png`. Внутренние страницы сразу получают новый вид через общие стили, их шаблоны доводит тикет 02.

## Критерии приёмки

- [ ] `docs/design-brief.md` описывает систему B: токены, шрифты, компоненты, принципы, ссылки на макеты
- [ ] В main.css есть токены и компоненты из границы «Дизайн-система». Manrope нигде не упоминается. Unbounded и Golos Text подключены через @font-face с `font-display: swap`, основное начертание в preload
- [ ] Главная на 1280 и 375 сопоставлена с макетами: порядок блоков и раскладка совпадают. Отличия перечислены в отчёте с причиной. Шаблонных примет из истории 1 нет
- [ ] Hero: картинка через `{% image %}` (eager, `fetchpriority=high`, ширина и высота заданы). Подписи узлов и точка неисправности — HTML поверх картинки в процентах. Варианты лежат в `<picture>`, для неактивных — `loading=lazy`. Перекрёстная смена 300 мс, при `prefers-reduced-motion` без анимации. Карточка показывает подсказку, услугу со ссылкой, цену «от …» или «по запросу» и «Записаться» с `data-lead-open` и `data-service`. Без JS симптомы — ссылки на услуги. На 375 картинка не обрезает трактор и не даёт горизонтальной прокрутки
- [ ] `tests/xray.test.mjs` в jsdom проверяет поведение из «Тестовых швов»
- [ ] `symptoms[]` — стартовый набор из истории 4 — лежит в `home.md`, в схеме `page-home` и в Sveltia (`system` — select из шести значений). `npm run validate` проходит
- [ ] На главной нет названий краёв, в том числе в подвале. Края остаются в JSON-LD `areaServed`
- [ ] Меню: Услуги, Каталог, Статьи, Доставка, О компании, Контакты. Текущий раздел отмечен `aria-current`. Гамбургер работает с клавиатуры
- [ ] На ширине ≤ 768 есть липкая панель «Позвонить» / «Заявка», контент не прячется под ней. Телефон доступен в шапке на всех ширинах
- [ ] Контраст AA, `:focus-visible` виден, цели касания ≥ 44 px, иконки — один набор SVG, без эмодзи
- [ ] Скриншоты главной на 1280 и 375 просмотрены и доведены, по правилу Шанель убрано одно лишнее украшение
- [ ] `npm test` зелёный. Тесты, завязанные на старую разметку, обновлены без ослабления смысла. CSS ≤ 40 КБ gzip, JS ≤ 30 КБ gzip
