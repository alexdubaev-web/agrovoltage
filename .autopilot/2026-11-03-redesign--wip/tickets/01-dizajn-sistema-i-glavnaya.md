## Что должно заработать

У сайта новая визуальная система по `docs/design-brief.md`: палитра, шрифты Unbounded и Golos Text, шкала, скругления, базовые компоненты. Новая шапка, подвал, мобильная липкая панель «Позвонить / Заявка», модальное окно заявки и баннер согласия. Главная собрана по раскладке брифа. В первом экране интерактивная схема трактора с выбором симптома и карточкой диагноза. Ниже идут этапы ремонта, услуги строками по системам, модели John Deere, полоса с фото «Выезжаем к технике», товары, регионы, FAQ, статьи и контакт-полоса. Внутренние страницы сразу получают новый вид через общие стили. Их шаблоны доводит тикет 02.

## Критерии приёмки

- [ ] В main.css есть токены и компоненты из `interfaces.md` — граница «Дизайн-система». Manrope нигде не упоминается. Unbounded и Golos Text подключены через @font-face, с preload основного начертания
- [ ] Главная на 1280 и 375 соответствует раскладке брифа. В ней нет шаблонных примет из §Принципы 3: надписей капсом над заголовками, строк через «·», «→» в кнопках, одного выделенного слова в заголовке
- [ ] Схема трактора — инлайн-SVG с цепями `data-system` start/charge/ecu/cab/climate. Кнопка симптома (`button[aria-pressed]`) подсвечивает свою цепь (Fault или Frost), прорисовывает её за 400 мс и обновляет карточку диагноза: подсказка, услуга со ссылкой, цена «от …» или «по запросу», «Записаться» с `data-lead-open` и `data-service`. Без JS симптомы — это ссылки на услуги. При `prefers-reduced-motion` прорисовки нет. Всё это проверяет `tests/symptoms.test.mjs` в jsdom
- [ ] `symptoms[]` — стартовый набор из истории 4 — лежит в `home.md`, в схеме `page-home` и в Sveltia (`system` — select из пяти значений). `npm run validate` проходит
- [ ] Меню: Услуги, Каталог, Статьи, Доставка, О компании, Контакты — без «Регионов». Текущий раздел отмечен `aria-current`. Мобильное меню работает с клавиатуры
- [ ] На ширине ≤ 768 есть липкая панель «Позвонить» и «Заявка». Телефон виден в шапке на всех ширинах
- [ ] `:focus-visible` виден, контраст основного текста не ниже AA
- [ ] Скриншоты главной на 1280 и 375 просмотрены и доведены, по правилу Шанель убрано одно лишнее украшение
- [ ] `npm test` зелёный. Тесты, завязанные на старую разметку, обновлены без ослабления смысла. CSS ≤ 40 КБ gzip, JS ≤ 30 КБ gzip
