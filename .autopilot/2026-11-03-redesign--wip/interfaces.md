# Границы и правила проекта (редизайн)

Этот файл читай первым. Затем `notes.md` из этой же папки: там ссылки на описание существующего кода. Готовые имена коллекций, фильтров, партиалов и data-атрибутов лежат в `.autopilot/2026-11-03-agrovoltage-site/interfaces.md`. Используй их, новых синонимов не заводи.

## Правила проекта (из прошлой сборки, действуют)

- Хостинга и домена пока нет, всё проверяется локально. Индексация закрыта до `INDEXABLE=true` и `SITE_URL`.
- Заявки и заказы уходят на почту и в MAX. Корзина без онлайн-оплаты, заказ — это заявка.
- Регионы: Ставропольский и Краснодарский край, берутся из `settings.regions`. Телефон +7 962 001 19 90 — из `settings.phone`. **Названия краёв не показываются на главной** (пользователь: «ньюансно а не на главной»). Видимо — только /regiony/, страницы краёв, /kontakty/, /dostavka/. В JSON-LD `areaServed` остаются.
- Факты о компании не выдумываются. Всё неизвестное — видимая заглушка «[… — впиши]» или «[уточнить]». Тестовые позиции помечены `demo: true`.
- Без JS-фреймворков и CSS-фреймворков. Новые npm-зависимости не ставятся.
- Фирменные логотипы John Deere не используются. Жёлтый цвет тоже не используется.

## Границы, решённые в спецификации

### Дизайн-система — `src/assets/css/main.css`, `src/_includes/layouts/base.njk`, `src/_includes/partials/` (владелец: тикет 01)

Эталон вида — макеты `docs/mockups/home-desktop-b-xray.png` и `docs/mockups/home-mobile-b-xray.png`. Открой их и смотри, прежде чем верстать.

- Токены — CSS-переменные:
  - палитра: `--bg`, `--surface`, `--ink`, `--muted`, `--forest`, `--brand`, `--live`, `--frost`, `--fault` (значения — в spec.md, «Решения по реализации»);
  - шрифты: `--font-display` (Unbounded), `--font-text` (Golos Text);
  - шкала: `--step-0…--step-5` (16/18/22/28/40/56);
  - скругления: `--r-btn` 12, `--r-field` 10, `--r-card` 16, `--r-plane` 24, кнопки-пилюли симптомов — 999px;
  - отступы секций: `--space-section`.
- Базовые компоненты, которыми тикет 02 собирает внутренние страницы:
  - `.btn`, `.btn--primary`, `.btn--ghost`;
  - `.btn-round` — круглая кнопка-стрелка из строк услуг;
  - `.section`, `.section__head`;
  - `.service-list` / `.service-row` — строки услуг с миниатюрой, ценой и `.btn-round`, `.service-group` с подзаголовком группы;
  - `.steps` — нумерованная последовательность на линии;
  - `.faq` (на `details`);
  - `.price-table`;
  - `.plane` — белая крупная плоскость;
  - `.tag`;
  - `.prose` — текст статей и документов;
  - `.grid-products` — сетка карточек товара;
  - `.crumbs`;

  - `.photo-band` — широкая фото-полоса с текстом и кнопкой.

  Тикет 01 описывает каждый одной строкой в разделе «Что построил тикет 01» ниже. Тикет 02 новых глобальных компонентов не вводит. Если чего-то не хватает, он дописывает стили только в конец `main.css` под комментарием `/* pages */`.

## Тестовые швы

- `tests/seo-headings.test.mjs` (тикет 02) — по всему dist/ (кроме admin/) проверяет:
  - один H1 на странице;
  - нет пропусков уровней заголовков;
  - уникальные title длиной 50–70 символов;
  - уникальные description длиной 120–160 символов;
  - alt у `img` внутри `picture` в контенте.
- `tests/xray.test.mjs` (тикет 01) — в jsdom: кнопки симптомов с `aria-pressed`, смена активного варианта картинки, перемещение точки, обновление карточки (подсказка, ссылка на услугу, цена, `data-lead-open` + `data-service`), работа без JS — ссылки.
- `tests/content-copy.test.mjs` (тикет 03) — в контенте и settings нет стоп-штампов из истории 10. Длины `seo.title` и `seo.description` в данных проверяются по тем же правилам.
- Остальные тесты прошлой сборки остаются. Если тест проверял старую разметку, его можно обновить, но смысл проверки должен сохраниться.

## Команды и запреты

- Проверка: `npm test`. Один файл: `node --test tests/<файл>.test.mjs` (нужен собранный dist/).
- **`npm test` и `npm run dev` пишут в один dist/.** Перед `npm test` останови dev-сервер, если он запущен (порт 8080). Просмотр в браузере — после `npm run build` через `npm run dev` или через собранный dist/. Оркестратор сам перезапустит dev после сборки.
- Не трогать: `.autopilot/`, `AGENTS.md`, `CLAUDE.md`, `backend/`, `public/api/`, `docs/adr/`.
- Окружение: Windows 11, Git Bash, Node 24, PHP 8.3, `python`.
