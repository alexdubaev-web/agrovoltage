# 05 — Картинки сайта через /codex-image

**Требования:** R04
**Зависит от:** 02, 03
**Зона:** `src/assets/images/` · поля `image`, `images`, `cover` в `src/content/**` · `src/_data/settings.json` (только `seo.ogImage`)
**Волна:** 3
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Вместо заглушек сайт показывает сгенерированные тематические картинки:
- на первом экране главной — тёмно-зелёный современный трактор в поле на юге России и мастер-электрик;
- по картинке на каждую услугу, категорию и товар;
- обложки статей;
- OG-картинка с логотипом.

На картинках нет логотипов John Deere и других брендов, водяных знаков и случайного текста.

## Из брифа, дословно

> «картинки для сайта генерируй с помощью /codex-image»

## Разделы спецификации

История 4. Правило про чужие логотипы — в `interfaces.md`.

## Критерии приёмки

- [ ] Все картинки сгенерированы скиллом `codex-image` (вызов через Skill tool) и лежат в `src/assets/images/`
- [ ] У каждой услуги, категории, товара и статьи заполнено поле картинки, и файл существует. `npm run build` и `npm test` проходят
- [ ] Заданы hero главной и OG-картинка 1200×630
- [ ] На картинках нет брендовых логотипов, надписей и водяных знаков. Проверено просмотром каждой
- [ ] Исходник каждой картинки не больше 2 МБ, итоговый вес страниц укладывается в бюджет сборки
