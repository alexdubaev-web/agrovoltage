## Что должно заработать

Заказ из корзины уходит только с товарами, которые есть в каталоге, и с ценами из каталога. Регионы на страницах берутся из настроек. Таблица характеристик товара не вылезает за край на телефоне. Пустое поле порядка, сохранённое из Sveltia, не ломает сборку. На сайте нет неподтверждённых фактов о компании.
